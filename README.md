# Manual Testing – SauceDemo

Manual testing project performed on [saucedemo.com](https://www.saucedemo.com), a demo e-commerce site used for QA practice.

## What I Did
- Designed and executed manual test cases covering login, product listing, cart, and checkout flows
- Identified and documented 2 bugs, including steps to reproduce, expected vs. actual results, and severity
- Followed standard manual testing practices: test case design, execution, and bug reporting

## Skills Demonstrated
- Manual test case design
- Bug reporting and documentation
- SDLC/STLC fundamentals
- Attention to detail in functional testing

## Files
- `test-cases.[ext]` – Test cases written for the site
- `bug-reports.[ext]` – Bug reports with reproduction steps
